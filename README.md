## Featured Projects

**AES-GCM GPU Encryption Engine** — `C++17` `CUDA 13` `Cryptography`

AES-128/256-GCM written from scratch and validated against all 7 NIST SP 800-38D test vectors. CUDA AES-CTR kernels keep the S-Box in shared memory, round keys in constant memory, and state register-resident — no DRAM spill, coalesced 128-bit loads. 18.7× GPU speedup at 0.76 GB/s on an RTX 3050, with GHASH reformulated as a parallel GF(2¹²⁸) sum using butterfly tree-reduction. Hardened with constant-time tag comparison and immediate plaintext zeroing on auth failure.

**Chromatic Revival** — `Python` `PyTorch` `docTR` `Gradio`

Zhang et al. (2016) CNN colorization in Lab space, predicting ab chrominance from L in under 0.5s per image, plus a docTR (DBNet + CRNN) OCR pipeline with CLAHE preprocessing that beat EasyOCR on printed documents. Ships as a threaded Tkinter desktop app and a Gradio Space serving a 123 MB Caffe model over Git LFS.

**MotionCube** — `Processing` `Serial Communication`

Real-time 3D motion tracking that visualizes live sensor orientation, rendering roll and pitch as an interactive cube.
